@E P1-1 | 原則1-1 | ～が増えている（数・量が主語）
= The number of + 可算名詞の複数形 + is increasing
= The amount of + 不可算名詞 + is increasing
! the number / amount という単数の名詞が主語なので動詞は is（are ではない）。a number of + 複数名詞 (= several) は複数扱い。
! 「～が減っている」は increasing を decreasing にする。
! Cars in this town are increasing. のような形は受験の作文では避ける。
@S 例1 | この町の車が増えている
> The number of cars in this town is increasing.
~ P1-1 : The number of ; is increasing
@S 例2 | 大気中の二酸化炭素が年々増加している
> The amount of carbon dioxide in the atmosphere is increasing year by year.
~ R1-2 : The amount of ; is increasing
@E P1-2 | 原則1-2 | ～が増えている（増えつつある～が…している）
= An increasing number of + 可算名詞の複数形 + are (V)ing
= An increasing amount of + 不可算名詞 + is (V)ing
! more and more ～ とすることもできるが口語的。
@S 例3 | 最近では海外に行く日本人が増えている
> These days an increasing number of Japanese people are traveling abroad.
~ P1-2 : an increasing number of ; are traveling
~ F1-1 : These days
