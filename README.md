# 英作文 表現ノート

英作文の表現（原則1〜70・頻出表現・例題の解説）と例文を覚えるための Web アプリ。

- **表現カード**：日本語 → 英語の型（逆向きも可）。裏面に注意点・誤用例・本文の解説と、その表現を使っている例文を表示。
- **例文トレーニング**：日本文を英訳 → 模範解答と比較。解答中の各表現がどこに使われているかをマーカーで表示し、タップで表現の説明を開く。
- **追加**：AI チャットで表現・例文を追加（本と同じ形で表現をまとめ、例文と既存の表現へのリンクを作る）。claude.ai 版はアプリ内で AI を呼べる。GitHub Pages 版は「依頼文をコピー → 任意の AI チャットに貼る → 返ってきた JSON を貼り付けて取り込む」。追加分はブラウザに保存（claude.ai 版はアカウントにも同期）。
- 間隔反復（もう一度／あやふや／覚えた）で復習日を管理。記録はブラウザに保存（Artifact 版ではアカウントにも同期）。

## 構成

```
data_src/principles.txt   原則のまとめ（原則1〜70：意味 → 英語の型 → 注意）
data_src/part1-4.txt      本文から書き起こした表現と例文（書式は tools/build_data.py の冒頭）
tools/build_data.py       data_src → data.js（まとめの行に本文の解説を統合し、例文のハイライト位置を計算）
tools/build_site.py       index.html と dist/artifact.html（単一ファイル版）を生成
app/                      body.html / style.css / app.js
```

```
python3 tools/build_site.py   # data.js・index.html・dist/artifact.html を再生成
```

`index.html` をブラウザで開けば動く（サーバー不要）。

## 未収録の範囲

スキャンが崩れていて読めなかった、または添付に含まれていなかったページは本文の解説・例文が未収録（原則のまとめは1〜70すべて収録済み）：
p.188–189、pp.250–251、pp.254–263（原則55・56 の本文）、pp.292–319、p.328 以降。
